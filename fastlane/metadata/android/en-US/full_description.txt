Turn your 5G phone into a private SOCKS5 proxy for your laptop, tablet and other devices. Share your unlimited 5G/4G data over Wi-Fi, hotspot or USB tethering — no root required.

Perfect for: sharing 5G to a laptop on the go, bypassing hotel/café Wi-Fi limits, giving IoT or dev boards cellular access, or getting a real mobile IP for testing.

Features:
- No root, native C engine (epoll) — fast, stable, up to 1000 concurrent connections
- TCP (CONNECT) + UDP (ASSOCIATE and UDP-in-TCP 0x04) with IPv4, IPv6 and domain names
- All traffic forced over cellular via Network.bindSocket(); Wi-Fi is LAN only
- LAN-only listener (Wi-Fi / hotspot / USB + loopback health check) — never exposed on cellular
- Optional username/password auth (RFC 1929): set both to enable, empty = open proxy (use on trusted LAN only)
- Auto heartbeat & health check (every 10s) with auto-restart, real status callback, foreground notification with POST_NOTIFICATIONS on Android 13+
- Display of Wi-Fi / hotspot / USB / cellular IPs

How to use:
1. Set port (default 1080) and optional auth, tap Start
2. App shows proxy address for Wi-Fi / hotspot / USB
3. On your other device set SOCKS5 proxy to that address:port

Security:
- Listener binds only to LAN interfaces, never to cellular
- Credentials excluded from cloud / device transfer / adb backup

Network usage (only when stated):
- connectivitycheck.gstatic.com/generate_204 — cellular health check
- api.ipify.org — show cellular public IP on Refresh
